# Code comments

## Usage

Automatic use is disabled. Invoke with `$code-comments` in Codex or
`/code-comments` in Claude Code and Cursor.

Claude Code discovers the shared skill through `.claude/skills/code-comments`,
a relative symlink to this directory.
