Standard paper sizes. Each variant specifies the short side followed by the long side.

**Added in KCL 4.0.**

```kcl
type SheetSize {
  | AnsiA
  | AnsiB
  | AnsiC
  | AnsiD
  | AnsiE
  | IsoA0
  | IsoA1
  | IsoA2
  | IsoA3
  | IsoA4
}
```




### Variants

| Variant | Description |
|---------|-------------|
| `AnsiA` | ANSI A: 8.5 inches by 11 inches. |
| `AnsiB` | ANSI B: 11 inches by 17 inches. |
| `AnsiC` | ANSI C: 17 inches by 22 inches. |
| `AnsiD` | ANSI D: 22 inches by 34 inches. |
| `AnsiE` | ANSI E: 34 inches by 44 inches. |
| `IsoA0` | ISO A0: 841 millimeters by 1189 millimeters. |
| `IsoA1` | ISO A1: 594 millimeters by 841 millimeters. |
| `IsoA2` | ISO A2: 420 millimeters by 594 millimeters. |
| `IsoA3` | ISO A3: 297 millimeters by 420 millimeters. |
| `IsoA4` | ISO A4: 210 millimeters by 297 millimeters. |
