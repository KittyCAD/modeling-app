Standard paper sizes, with the shorter edge as the width.

**Added in KCL 3.0.**

```kcl
type PaperSize {
  | A3
  | A4
  | Letter
  | Legal
}
```




### Variants

| Variant | Description |
|---------|-------------|
| `A3` | ISO A3: 297mm by 420mm. |
| `A4` | ISO A4: 210mm by 297mm. |
| `Letter` | US Letter: 8.5in by 11in. |
| `Legal` | US Legal: 8.5in by 14in. |
