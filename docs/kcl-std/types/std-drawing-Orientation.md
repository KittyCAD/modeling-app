The direction of the paper's longer edge.

**Added in KCL 3.0.**

```kcl
type Orientation {
  | Portrait
  | Landscape
}
```




### Variants

| Variant | Description |
|---------|-------------|
| `Portrait` | The longer edge is vertical. |
| `Landscape` | The longer edge is horizontal. |
