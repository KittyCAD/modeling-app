Determines which side length defines the width of a drawing sheet.

**Added in KCL 4.0.**

```kcl
type SheetOrientation {
  | Landscape
  | Portrait
}
```




### Variants

| Variant | Description |
|---------|-------------|
| `Landscape` | Use the long side as the width. |
| `Portrait` | Use the short side as the width. |
