# Sketch suggestion seed cases

These four preconstraint KCL sketches were derived from the pinned modeling-app
test files named in `manifest.jsonl`. The target relation was removed, and
some coordinates were adjusted to create a near-miss for the suggestion POC.
The two `*_dimension_probe.kcl` files exercise dimension changes for equal
radius and tangency.

The seeds and their generated variants are not CAD-reviewed training examples.
The weak-label experiment in `../sketch_constraint_weak_poc/` treats the
omitted target constraint as a retrieval target only.
