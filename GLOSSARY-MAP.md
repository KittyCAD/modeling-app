# Glossary map

This repository has multiple domain contexts. Read the glossary for each context relevant to the task.

Only contexts with recorded terminology are indexed here. Add entries as other context glossaries are written.

| Context | Scope | Code paths | Glossary | ADR directory |
| --- | --- | --- | --- | --- |
| Design Studio application | Application terminology, navigation, workspaces, modeling interfaces, and Zookeeper | `src/`, `packages/ui-components/` | [Glossary](src/GLOSSARY.md) | `src/docs/adr/` |
| KCL language | Language and interpreter terminology for sketches, constraints, modeling operations, and geometry | `rust/` | [Glossary](rust/GLOSSARY.md) | `rust/docs/adr/` |

System-wide decisions belong in `docs/adr/`. Context ADR directories are created when decisions need to be recorded.
